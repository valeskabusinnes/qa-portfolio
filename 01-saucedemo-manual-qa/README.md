# SauceDemo - Manual QA Project

## Project Overview

SauceDemo is a web-based e-commerce application used to simulate an online shopping experience.

This project documents an independent manual QA assessment of the application's main user flows, with a focus on functional testing, negative testing, exploratory testing and regression coverage.

**Project type:** QA Portfolio Project  
**Application:** SauceDemo  
**Testing approach:** Manual Testing  
**Role:** QA Analyst

---

## Objectives

The main objectives of this project are to:

- Validate the main e-commerce user flows.
- Identify functional and usability issues.
- Verify expected behavior under positive and negative scenarios.
- Design and execute manual test cases.
- Document defects with clear reproduction steps.
- Evaluate the application's readiness from a functional QA perspective.

---

## Scope

The following areas are included in the testing scope:

- Login
- Product listing
- Product sorting
- Product details
- Shopping cart
- Checkout
- Order completion
